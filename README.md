# Лабораторна робота №1: Налаштування системи тактування та обробники переривань (ISR) у PSoC 4

**Виконав:** Студент 4-го курсу Грігор Іон Георгійович  
**Спеціальність:** 123 - Комп'ютерна інженерія  
**Університет:** УжНУ, Інженерно-техничний факультет

## Мета роботи
Ознайомитися з тактуванням та обробкою переривань (ISR) для мікроконтролерів PSoC 4 за допомогою PSoC® Creator™, 
а також реалізувати асинхронне оброблення подій від таймера та фізичної кнопки.

## Варіант 4 (Параметри конфігурації)
- **Частота IMO:** 16 МГц
- **Частота BUS CLK:** 4 МГц (Дільник: 4)
- **Тактування таймера (Clock_1):** 1 МГц (Тік = 1 мкс)
- **Період переривання Timer_1:** 250 мкс (Значення регістру Period = 249)
- **Затримка CyDelay в main():** 1 мс

## Схема проєкту (TopDesign)
Проєкт містить такі компоненти:
- `Clock_1` (1 MHz)
- `Timer_1` (Режим Timer Counter TCPWM, подія Terminal Count)
- `isr_Timer` (Переривання таймера)
- `Pin_Button` (Цифровий вхід P0[7], режим переривання Falling Edge)
- `isr_Button` (Переривання фізичної кнопки)
- `Pin_Main` (Вихід P0[3]) та `Pin_ISR` (Вихід P0[2])
